# Introduction to JavaScript

In this course we will learn the fundamentals of web development with JavaScript. We will understand how the language works and how to use it to build dynamic, interactive web projects.

## Syllabus

### 1. Variables

- Declaring variables with `var`, `let` and `const`.
- Differences between each kind of declaration and good practices.
- Global, local and block scope.
- Assigning and reassigning values.

### 2. Data types

- Primitive types: `string`, `number`, `boolean`, `null` and `undefined`.
- Composite types: objects and arrays.
- String concatenation and template literals.
- Basic operations and type conversion.
- Checking types with `typeof`.

### 3. Functions

- Declaring and calling functions.
- Parameters and arguments.
- Returning values with `return`.
- Anonymous functions and arrow functions.
- Variable scope inside a function.

### 4. DOM and events

- Selecting elements in the document.
- Changing content, attributes and styles.
- Reading and validating form data.
- Handling events with `addEventListener`.
- Using the `event` object.
- Practical project: building an interactive calculator.
